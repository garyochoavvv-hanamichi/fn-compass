# FN Compass

Mobile-first Fortnite competitive companion.

- Tournament calendar is refreshed automatically from the official Fortnite Competitive calendar for NAC and BR.
- Supports Solo, Duo and Trio filters, BR/Reload and platform filters.
- One active tournament controls Home, Map and Ranking.
- Home tracks points manually per game and calculates the remaining pace needed.
- Map stays inside FN Compass using the tournament's Fortnite.GG view.
- Ranking is only embedded when the updater has verified a matching Fortnite Tracker event; otherwise FN Compass shows a neutral unavailable state instead of opening the wrong tournament.
- The scheduled workflow preserves the last valid calendar if a source is temporarily blocked.

GitHub Pages can serve this repository directly from the `main` branch root.
